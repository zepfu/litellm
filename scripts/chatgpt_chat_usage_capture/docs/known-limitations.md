# Known limitations

- Fixture-backed collection is the supported path in this slice. Live Playwright login is operator-authorized and separate.
- Temporary and deleted chats are not recoverable from ordinary history.
- Working remaining is an application estimate, not a proven charging policy.
- Seed `config.yaml` keeps `pro200-*-chat` bucket IDs for collector tests; `config.example.yaml` uses spec IDs.
- Local API auth default token is `local-dev` when `local_api_token` is unset. Bind remains loopback.
